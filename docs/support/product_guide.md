# Japanese Helper — как устроено приложение

Краткое описание функций для пользователей. Демонстрационное содержимое справочного центра (День 33).

Japanese Helper помогает учить японские слова уровней JLPT: показывает слово дня, объясняет его, подбирает примеры и картинки. Приложение работает на Android и iOS и требует подключения к интернету.

## Главный экран

На главном экране показывается случайное слово выбранного уровня JLPT (N5–N1) с фуриганой и переводом. Уровень меняется в выпадающем меню.

## Функции для слова

- Kanji Word Set — слова с тем же кандзи.
- AI Explanation — объяснение слова от модели.
- Temperature Description — примеры предложений с разной «температурой» модели.
- Model Comparison — сравнение ответов нескольких моделей.
- Create pic — картинка к слову (см. «Генерация картинок»).

## AI Agent и поддержка

Экран AI Agent — чат с ассистентом, который помнит контекст разговора и может отвечать по документации. Экран «Поддержка» отвечает на вопросы о приложении с учётом вашего обращения (тикета).

## Аккаунт

Аккаунт нужен, чтобы сохранять прогресс и подписку между устройствами. Вход — по email и паролю или через Google (см. «Вход и авторизация»).
